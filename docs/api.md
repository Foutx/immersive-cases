# API каталога

Локальный запуск без дополнительных пакетов:

```powershell
python -m api.app
```

Адрес: http://127.0.0.1:5000/. Корень открывает сайт каталога. Описание API доступно по /api/info. Схема БД обновляется автоматически. База по умолчанию data/immersive_cases.sqlite3; переменная DATABASE_PATH также поддерживается.

Для просмотра тестового примера и черновиков только локально:

```powershell
python -m api.app --db data/demo.sqlite3 --include-drafts --port 5001
```

Режим include-drafts включает ВСЕ статусы, в том числе rejected. Он задаётся только при старте сервера и не может быть включён параметром запроса. Не включайте его при публичном размещении. Обычный режим отдаёт только published во всех маршрутах карточек, фильтров и экспорта. Пустая выдача рабочей базы сейчас ожидаема: реальных опубликованных карточек ещё нет.

## Маршруты GET

- /api/events: items, total, page, per_page. Параметры q, country (JP), year (2023), tag (xr), has_video (true/false), page (от 1), per_page (1–100). Сортировка по updated_at и ID.
- /api/events/{id}: полная карточка с proofs, tags, parties, claims/evidence. Неопубликованная или отсутствующая карточка даёт 404.
- /api/filters: доступные страны, годы и теги только для видимой выборки.
- /api/collection-status: last_import, last_successful_import, last_collection_at. Дата реального сбора пока null, потому что отдельного достоверного журнала завершённых обходов нет. Внутренние ошибки и содержимое входных пакетов не выдаются.
- /api/export?format=json или format=csv: скачивание всей отфильтрованной выборки, без пагинации. Применяются те же фильтры q/country/year/tag/has_video. JSON содержит полные карточки, CSV содержит основные поля. Выборка свыше 10000 отклоняется с кодом 413; нужно сузить фильтры. CSV защищает текстовые поля от интерпретации как формул.

Пример: /api/events?q=проекции&country=JP&has_video=true&per_page=10

Поиск FTS5 по словам в названии и описании, все слова должны присутствовать. Это не LLM-поиск и не поиск по словоформам. has_video обозначает наличие подтверждения типа video, не ручную проверку или доступность ролика.

Ошибки параметров: 400; отсутствующий маршрут/карточка: 404; запись через POST и другие методы: 405; проблема БД: 503. SQL-параметры передаются отдельно от текста запросов, пользовательские FTS-операторы не исполняются. Кеширование ответов выключено.

## Устройство

services/catalogue.py содержит запросы к БД. api/app.py предоставляет WSGI-приложение create_app(db_path=None, include_drafts=False), которое впоследствии можно подключить к существующему backend. Локальный сервер wsgiref слушает только 127.0.0.1. Он предназначен для разработки, не для публичной нагрузки. Для размещения потребуется полноценный WSGI-сервер/интеграция с сайтом; черновики должны оставаться закрытыми.

Flask не установлен из-за TLS-ошибки доступа к PyPI, поэтому текущая реализация использует стандартную библиотеку. Пользовательские операции записи и модерации намеренно отсутствуют; их маршруты не защищены «скрытой ссылкой», а вообще не реализованы.

Проверки: python -m unittest discover -s tests -p "test_*.py". 44 офлайн-теста, включая видимость черновиков, поиск, фильтры, экспорт, ошибки параметров и отклонение записи.

### Фильтр по механизму погружения

`has_mechanism=true|false` поддерживается в `GET /api/events` и `GET /api/export`.
`true` требует утверждение `immersion_mechanism` и хотя бы одну связанную цитату.
В списке `has_mechanism` возвращается как 0/1. Наличие цитаты не означает ручной проверки.
Режим видимости не изменён: в обычном каталоге черновики не выдаются.
