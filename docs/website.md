# Сайт с SQLite

Восстановлен дизайн из immersive-cases-source.zip и текстовая редакция site-text-update.zip. Архивы present-site не использовались. Новый web/index.html загружает данные через /api/events; серверная шаблонизация Flask не требуется. Цвета и композиция сохранены, список/фильтры/карточки подключены к API.

## Локальный просмотр восстановленных данных

```powershell
python -m api.app --db data/site-preview.sqlite3 --include-drafts --port 5002
```

Открыть http://127.0.0.1:5002/. В этой локальной базе четыре исторических кандидата из site-data.zip. Все остаются draft, факты и актуальность ссылок не перепроверены. Подтверждённых видео нет. Это не публикация данных. Файл SQLite исключён из Git; на другом компьютере нужно импортировать исходный raw_candidates.json командой import-db с --db-path data/site-preview.sqlite3.

## Обычный режим

```powershell
python -m api.app
```

Рабочая база data/immersive_cases.sqlite3, только published. Пока она пуста. Сервер слушает только 127.0.0.1, публичное размещение этим изменением не выполнялось.

## Интерфейс

Поиск по словам названия/описания, фильтры страны, года, тега и наличия видео; пагинация по 20; раскрытие карточки с источниками и подтверждениями; JSON/CSV; даты импорта. Список загружается JavaScript, при его отключении есть ссылка на JSON. При сетевой ошибке предусмотрен повтор загрузки.

Страны и города старых кандидатов сохранены исходной строкой location_text. Они показаны внутри карточки; фильтр страны заполнится после структурирования country_code. Не делаем вывод о стране автоматически по названию. Признаки иммерсивности без цитат отмечены как незаполненные. Дата сбора неизвестна и не заменяется датой сегодняшнего импорта.

Кнопка «Скачать найденное» учитывает применённые фильтры. Общие ссылки скачивания выгружают все карточки, доступные в текущем режиме. В обычном режиме черновики скрыты и в API, и в экспорте.

Проверены в браузере загрузка четырёх карточек, раскрытие описания/источника, поиск Borderless и сброс фильтров. API и статические маршруты покрыты офлайн-тестами; мобильная вёрстка сохранена и дополнена адаптивными правилами, отдельная визуальная проверка на телефоне пока не выполнена.

## Дополнение: механика погружения

Добавлены блок «Как устроено погружение», метка «Механизм с цитатой» и фильтр
«Погружение». Он применяется и к выгрузке. Цитаты остаются на языке источника;
ссылки ведут к страницам, из которых их извлёк парсер. Цитата в тексте не означает
ручной фактчек. Если данных нет, карточка говорит об этом. Дизайн и видимость
черновиков оставлены прежними.
